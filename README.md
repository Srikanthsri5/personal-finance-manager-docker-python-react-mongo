# Personal Finance Manager

This project is a personal finance manager. It uses a React frontend and a Python (FastAPI) backend.

## Status
The repository has been wiped clean of any Docker configurations and preexisting application logic. It currently serves as an empty boilerplate to start coding from scratch.
